# Meetings（MTG議事録・文字起こし）

このディレクトリには、会議の文字起こしと議事録が格納されています。

## 文字起こしの自動取り込み（cortex-notetaker）

> **前提: クラスメソッド側が主催する Google Meet の会議のみ**が対象です。Gemini の文字起こしメモは主催者の Workspace で生成・共有されるため、**顧客側が主催する会議（先方の Google Meet / Teams / Zoom 等）は自動では入りません**。その場合は下の「議事録の手動生成」で取り込んでください。

対象の会議は、**運用は2つだけ**で文字起こしがこのディレクトリに自動で入り、議事録も自動生成されます（GitHub Actions `ingest-minutes`）。

1. **会議名に目印を入れる**（例:「**【kc】定例**」。目印は**ビューアの「操作」タブ**に「会議名に入れる目印」として出ています。名前のどこにあってもかまいません）
2. **招待に `cortex-notetaker` の bot を追加する**（定例はシリーズに1回。招待されていれば bot の参加は不要）

- 取り込むか否かは「bot を招待したか」で決まります。**社内だけの会議には bot を招待しない**でください（このリポジトリは顧客に見える前提）
- どの案件リポへ入るかは、**会議名に `[合図]` または `【合図】` が入っているか**だけで決まります（半角・全角どちらでも可・大小文字は問わない）。合図は既定で艦隊レジストリのキー。長くて打ちにくい案件だけ `ingest-config.json` の `meetingKey` に短い合図を書きます
  - **括弧の中身は合図そのもの。** `【KC定例】` のように他の文字が混ざると当たりません
  - **記号まで一致させます。** `_` と `-` は別物です
  - **`meetingKey` に括弧は書きません**（括弧は会議名の側に付けます）
- この案件で自動取り込みを使うかは `ingest-config.json` の `enabled` で宣言します（`/setup-project` ステップ12）

## 議事録の手動生成

**顧客側が主催する会議（自動取り込みの対象外）**や、Teams・Zoom等の文字起こし、手元のファイルからは、次のいずれかで議事録化します。

- **ビューアの投入フォーム**に文字起こしを渡す（Cortex に取り込まれ議事録が生成される）
- 文字起こしファイルをこのディレクトリに置いて `/create-minute` で生成する

```
/create-minute {文字起こしファイルのパス}
```

## ディレクトリ構成

```
会議/
├── Ph.1/                        # フェーズごと
│   └── YYYYMMDD/               # 日付ごと
│       ├── YYYYMMDD_minutes.md # 議事録（自動生成）
│       └── {元ファイル}.txt     # 文字起こし原本
├── templates/                   # 議事録テンプレート
│   └── minute-template.md
├── ingest-config.json           # 自動取り込みの設定（enabled / transcriptDir / 任意の meetingKey）
└── README.md                    # このファイル
```

## 対応する文字起こし形式

| ツール          | ファイル形式    | 備考                                    |
| --------------- | --------------- | --------------------------------------- |
| Google Meet     | `.txt`          | Gemini によるメモ（タイムスタンプ付き） |
| Microsoft Teams | `.docx`         | 自動文字起こし                          |
| Zoom            | `.txt` / `.vtt` | 文字起こし                              |

## 議事録からのコンテキスト活用

生成された議事録は以下のワークフローで活用されます：

1. **Decision Log への反映**: 毎晩の自動精製が議事録から決定事項を抽出（今すぐなら `/update-decision`）
2. **課題管理ツールの更新**: 定例会のアジェンダ課題に結果を反映
3. **コンテキスト探索**: AIが作業開始時に関連する議事録を自動参照
